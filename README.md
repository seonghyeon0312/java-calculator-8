# 문자열 계산기 (String Calculator)

입력된 문자열에서 숫자를 추출하여 합을 계산하는 프로그램입니다.  
쉼표(,) 또는 콜론(:)을 구분자로 사용하며, 커스텀 구분자도 지원합니다.  
잘못된 입력값에 대해서는 예외를 발생시킵니다.

---

## 1. 요구 기능 정리

1. **문자열의 숫자 합산 기능**
    - 입력된 문자열에 포함된 숫자의 합을 반환한다.
   

2. **기본 구분자 처리**
    - 쉼표(,) 또는 콜론(:)으로 구분된 숫자를 인식한다.
    - 문자열이 `"//"`으로 시작하고 `"\n"`으로 끝나는 문자로 시작하면 사이에 있는 문자열이 커스텀 구분자가 된다.


3. **예외 처리**
    - 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException` 발생
    - 예외에 해당되는 경우는 다음과 같다.
      1. 음수가 포함된 경우 예) `-1:2:3`
      2. 커스텀 구분자를 지정 형식이 잘못된 경우 예) `//*1*2*3`, `*\n1*2*3` 
      3. 문자열 입력 형식이 잘못된 경우 예) `1*2*3`, `//*\n1*2*3*`

---

## 2. 세부 기능 목록

| 구분 | 기능 설명 | 매개변수 (입력) | 출력 (결과) |
|------|------------|-----------------|--------------|
| 입력값 검증 | null, 빈 문자열, 음수, 비정상 문자 검사 | `"1,-2,3"` | 예외 발생 (`IllegalArgumentException`) |
| 구분자 추출 | 입력 문자열에서 사용할 구분자를 추출한다. <br> - `"//<구분자>\n"` 형태이면 커스텀 구분자 사용 <br> - 아니면 기본 구분자(`[,:]`) 사용 | `"//;\n1;2;3"` , `"1,2:3"` | 커스텀 구분자: `";"` <br> 기본 구분자: `[,:]` |
| 문자열 → 숫자 변환 | 구분자를 기준으로 문자열을 정수 리스트로 변환 | `"1;2;3"` , 구분자: `";"` | `[1, 2, 3]` |
| 합산 계산 | 숫자 리스트의 합을 계산 | `[1, 2, 3]` | `6` |
